HowTogo 고객 지원

HowTogo 를 써 주셔서 고맙습니다. 궁금한 점이나 불편한 점이 있으면 아래 이메일로 알려 주세요.

문의하기

이메일: howtogo.official@gmail.com

보통 3일 안에 답장 드립니다.

문의하실 때 아래 내용을 함께 적어 주시면 더 빨리 도와드릴 수 있어요.

  • 사용 중인 기기 (예: iPhone 15 Pro)
  • iOS 버전 (설정 → 일반 → 정보)
  • HowTogo 버전 (앱의 톱니바퀴 버튼 → 설정 맨 아래)
  • 어떤 화면에서 무엇을 했을 때 문제가 생겼는지, 가능하면 화면 캡처

자주 묻는 질문

장소는 어떻게 추가하나요?

  • 페이지의 장소 추가 칸(+)을 눌러 직접 입력할 수 있어요.
  • 구글맵, 애플 지도, 네이버 지도, 카카오맵 같은 지도 앱이나 인스타그램에서 공유 버튼 → HowTogo 를 고르면 바로 저장돼요. 목록에 HowTogo 가 없으면 공유 화면의 앱 목록 끝에 있는 더 보기에서 켜 주세요.

위젯은 어떻게 추가하나요?

홈 화면의 빈 곳을 길게 누른 뒤 왼쪽 위의 편집 → 위젯 추가 에서 HowTogo 를 고르세요. 잠금 화면에도 추가할 수 있어요.

다른 기기에서도 자료를 볼 수 있나요?

같은 Apple 계정으로 iCloud 에 로그인한 기기끼리는 자동으로 맞춰져요. 자료가 보이지 않으면 아래를 확인해 주세요.

  • 설정 → [이름] → iCloud 에 로그인되어 있는지
  • 인터넷에 연결되어 있는지
  • 처음 맞춰질 때는 몇 분 걸릴 수 있어요.

앱을 지웠다가 다시 설치하면 자료가 사라지나요?

iCloud 를 쓰고 있었다면 같은 계정으로 다시 설치했을 때 자료가 돌아와요. 톱니바퀴 버튼 → 설정 → 백업 → iCloud 동기화 가 켜져 있는지 확인해 주세요. iCloud 를 쓰지 않으면 앱 자료는 아이폰 전체 백업(iCloud 백업이나 컴퓨터 백업)에 함께 들어가요.

친구에게 페이지를 보내고 싶어요.

왼쪽 아래 버튼으로 페이지 설정을 열고 이 페이지 공유를 누르면 파일을 만들어 메시지, 카카오톡, AirDrop 으로 보낼 수 있어요. 받은 사람이 파일을 누르고 HowTogo 로 열면 페이지가 추가돼요. 방문 표시는 함께 보내지지 않아요. 무료로 쓰고 있고 페이지가 이미 2개라면, 받은 페이지를 추가하려면 페이지 무제한을 구매해야 해요.

길찾기를 누르면 원하는 지도 앱이 열리지 않아요.

톱니바퀴 버튼 → 설정 → 사용할 지도 앱 에서 원하는 앱을 고르세요. 목록에는 구글맵과 이 기기에 설치된 지도 앱만 보여요. 구글맵이 설치되어 있지 않으면 안내 창이 뜨고, 닫으면 브라우저의 구글맵 웹으로 열려요.

페이지는 몇 개까지 만들 수 있나요?

페이지 2개까지는 무료예요. 페이지 무제한을 한 번 구매하면 그 뒤로는 제한 없이 만들 수 있어요. 구독이 아니라서 다시 결제되지 않아요.

새 기기에서 구매한 내역이 보이지 않아요.

톱니바퀴 버튼 → 설정 → 페이지 → 구매 복원 을 눌러 주세요. 구매할 때 쓴 Apple 계정으로 로그인되어 있어야 해요.

환불받고 싶어요.

App Store 결제는 Apple 이 처리하므로 환불도 Apple 에 요청해야 해요. reportaproblem.apple.com 에서 신청할 수 있어요.
